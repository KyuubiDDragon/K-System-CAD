## Technology Stack

- **Frontend:** Vue 3, TypeScript, Vuetify 3, Pinia
- **Backend:** PHP 8, MariaDB, JWT Authentication
- **Socket Server:** Node.js, Socket.io, Express
- **Infrastructure:** Docker, Nginx, Apache

## Key Features

### Desktop Mode
Experience a unique Windows-style desktop interface with:
- Multiple resizable and draggable windows
- Start menu with categorized applications
- Taskbar with open window management
- Desktop icons with drag-and-drop positioning
- Customizable backgrounds and widgets

### Multi-Tenant Architecture
- Complete data isolation between organizations
- Custom branding per authority (logo, colors, app title)
- Feature flags to enable/disable modules per tenant
- Authority-specific custom fields

### Comprehensive Module Suite
- **Employee Management** - Departments, ranks, training, licenses
- **Reports** - Custom fields, templates, status workflow
- **Documents** - Dynamic areas with permissions
- **Calendar** - Events, groups, assignments
- **Messages** - Private and group messaging
- **Invoices** - Line items, PDF generation
- **Todo Lists** - Tasks with checklists and assignments
- **Map** - Location tracking with custom markers
- **Whiteboard** - Collaborative drawing
- **And much more...**
