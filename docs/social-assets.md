# Social assets

`social/public/city.png` was generated with the built-in Imagegen tool for this project, as a standalone Los-Santos-inspired launcher background. It contains no interface elements. The source is copied into the repository so deployment does not depend on a local Codex directory.

Generation prompt:

> Create a production-ready wide photographic background asset for a Los Santos roleplay social app launcher. NO UI, NO icons, NO text, NO logos, NO lettering, NO watermarks. Cinematic high-quality Los Santos-inspired southern California coastal city panorama at blue hour, skyline toward right, pier and ocean toward left, silhouetted palms framing edges, warm windows and hillside streets, mountains in distance. Realistic game-world environmental art, tasteful restrained colors, dark navy sky and amber lights. Main central area slightly calm with clear sky above skyline so app controls will later be overlaid; no foreground people or cars dominating frame. Wide landscape 1536x1024. This is ONLY the scenic background asset; do not include any interface or words.

App icons are original code-native SVG paths in `social/src/Icon.vue`, with five visual treatments in the stylesheet. Uploaded community icons replace individual app symbols. No third-party social-network brand icons are shipped.

`social/tests/fixtures/image.jpg` is copied from the existing CAD background for local upload/conversion tests only; it is not part of the Social production assets.
