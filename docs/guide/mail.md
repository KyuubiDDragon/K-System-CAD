# Mail System

K-Systems includes an integrated mail system for internal communication and external email management.

![Mail Interface](../public/images/messages/messages-inbox.png)

---

## Overview

The mail system provides:
- **Internal messaging** between users within K-Systems
- **External email integration** (if configured by administrator)
- **Folder organization** for managing messages
- **Attachments** support for sharing files
- **Rich text formatting** for professional communication
- **Search and filtering** to find messages quickly

---

## Accessing Mail

### Opening the Mail Module

**Method 1: Via Sidebar**
1. Click **"Mail"** or **"Messages"** in the sidebar
2. Opens your inbox

**Method 2: Via Search**
1. Press `Ctrl+K` / `Cmd+K`
2. Type "mail" or "messages"
3. Select from results

**Method 3: Via Desktop Mode**
1. Open Start Menu
2. Navigate to **Communication** > **Mail**
3. Double-click to open in new window

## Composing Messages

### Creating a New Message

![Compose Message](../public/images/messages/message-compose.png)

**Steps:**

1. **Click "Compose" or "+ New Message"**
   - Opens composition window

2. **Fill in recipients:**
   - **To:** Primary recipients (required)
   - **CC:** Carbon copy (optional - others who should see message)
   - **BCC:** Blind carbon copy (optional - recipients hidden from others)

3. **Enter subject:**
   - Clear, descriptive subject line
   - Helps recipients understand message purpose

4. **Write message:**
   - Use rich text editor for formatting
   - Toolbar options:
     - **Bold**, *Italic*, Underline
     - Font size and color
     - Bullet lists and numbered lists
     - Alignment
     - Links
     - Tables (if supported)

5. **Add attachments** (optional):
   - Click "Attach" or paperclip icon
   - Select files from computer
   - Multiple files supported
   - Check file size limits

6. **Send or Save:**
   - **Send** - Delivers message immediately
   - **Save as Draft** - Save to continue later
   - **Discard** - Cancel and delete

### Message Composition Tips

**Subject Lines:**
- ✅ "Meeting tomorrow at 2pm - Conference Room A"
- ✅ "Report review needed by Friday"
- ❌ "Hi" or "Question" (too vague)

**Message Body:**
- Start with greeting: "Hello [Name]," or "Hi Team,"
- Clear, concise content
- Use paragraphs for readability
- End with signature or name

**Formatting:**
- Use **bold** for important points
- Use bullet lists for multiple items
- Keep formatting simple and professional

## Replying and Forwarding

### Replying to a Message

**Reply (to sender only):**
1. Open message
2. Click **"Reply"**
3. Compose your response
4. Original message quoted below
5. Click **Send**

**Reply All (to all recipients):**
1. Open message
2. Click **"Reply All"**
3. Everyone in To/CC receives your reply
4. Compose response
5. Click **Send**

::: warning Reply All Caution
Use "Reply All" carefully. Only use when everyone needs to see your response. Avoid "Reply All" for simple acknowledgments.
:::

### Forwarding Messages

**Forward to someone else:**
1. Open message
2. Click **"Forward"**
3. Enter new recipient(s)
4. Optionally add your own message
5. Original message included below
6. Attachments are forwarded too
7. Click **Send**

**Use cases:**
- Share information with colleagues
- Escalate issues to supervisor
- Loop in additional team members

## Attachments

### Sending Attachments

**Attaching Files:**
1. While composing, click **"Attach"** or paperclip icon
2. **Select files** from your computer
3. Wait for upload to complete
4. Files appear in attachment area
5. **Remove** unwanted attachments with X button

**Supported File Types:**
- Documents: PDF, DOC, DOCX, XLS, XLSX, TXT
- Images: JPG, PNG, GIF
- Archives: ZIP, RAR
- Others: Depends on system configuration

**File Size Limits:**
- Typical limit: 10-25MB per file
- Total per message: 25-64MB
- Large files: Consider using document management system and linking instead

### Receiving Attachments

**Viewing Attachments:**
1. Open message with attachment (paperclip icon)
2. Scroll to **Attachments** section
3. See list of attached files with names and sizes

**Downloading Attachments:**
- Click **filename** or **Download** button
- File saves to your Downloads folder
- Scan with antivirus before opening if from external sources

**Previewing Attachments:**
- Some systems allow preview without download
- Click **Preview** or **eye icon**
- Works well for images and PDFs

::: warning Security
Only open attachments from trusted sources. Malicious files can harm your computer. When in doubt, consult IT department.
:::

## Mail Etiquette & Best Practices

### Professional Email Etiquette

**Subject Lines:**
- Clear and descriptive
- Indicate urgency if needed: "[URGENT]" or "[Time Sensitive]"
- Update subject when topic changes

**Greetings & Closings:**
- Start: "Dear [Name]," (formal) or "Hi [Name]," (casual)
- End: "Best regards," "Thank you," "Sincerely,"

**Message Content:**
- Get to the point quickly
- Use paragraphs for readability
- Proofread before sending
- Avoid all caps (LOOKS LIKE SHOUTING)
- Use proper grammar and spelling

**Response Time:**
- Reply within 24 hours when possible
- If you need more time, acknowledge receipt: "Thanks, I'll review and get back to you by Friday"

**Reply All:**
- Only use when everyone needs your response
- Don't "Reply All" to say "Thanks" - just reply to sender

### Managing Your Inbox

**Zero Inbox Strategy:**
1. **Read** new messages daily
2. **Respond** to urgent items immediately
3. **File** messages into folders
4. **Delete** unnecessary messages
5. **Flag** items needing follow-up

**Folder Organization:**
- **Projects** - By project name
- **Archive** - Old but important messages
- **FYI** - Informational, no action needed
- **Waiting** - Awaiting response from others

**Regular Maintenance:**
- Delete old messages (check trash folder)
- Archive completed project messages
- Unsubscribe from unnecessary notifications
- Review folders quarterly

## Troubleshooting

### Problem: Can't Send Messages

**Possible causes:**
- No recipient specified
- Invalid email address
- Attachment too large
- Network connection issue

**Solutions:**
1. Verify recipient addresses
2. Check attachment sizes (compress if needed)
3. Check internet connection
4. Try saving as draft and sending later
5. Contact administrator

### Problem: Messages Not Arriving

**For sender:**
- Check "Sent" folder to confirm it sent
- Verify recipient address is correct
- Check if message is in recipient's spam folder (external email)

**For recipient:**
- Check spam/junk folder
- Check filters aren't hiding message
- Ensure sender isn't blocked
- Refresh inbox

### Problem: Can't Attach Files

**Solutions:**
1. Check file size (may exceed limit)
2. Check file type (may be restricted)
3. Try different browser
4. Ensure stable internet connection
5. Upload to Document Management and link instead

### Problem: Mail Module Not Loading

**Solutions:**
1. Refresh page (F5)
2. Clear browser cache
3. Check if feature is enabled for your account
4. Contact administrator

## Security & Privacy

### Email Security

**Best Practices:**
- Don't share passwords via email
- Be cautious of phishing attempts
- Verify sender before opening attachments
- Don't click suspicious links
- Report spam to administrator

**Data Protection:**
- Messages are stored on K-Systems servers
- Access controlled by user permissions
- Administrators may have access for system maintenance
- Follow your organization's email retention policies

### Phishing Awareness

**Warning signs:**
- Unexpected attachments
- Urgent requests for personal information
- Misspelled sender addresses
- Poor grammar or formatting
- Requests to click links or download files

**If suspicious:**
1. Don't click any links or attachments
2. Don't reply
3. Forward to IT/administrator
4. Delete the message

## FAQs

**Q: Can I recall a sent message?**
A: Usually not possible once sent. Some systems may have a short window (30 seconds) to undo. Otherwise, send a follow-up message to clarify or correct.

**Q: How long are messages stored?**
A: Depends on your organization's policy. Check with administrator. Typically, messages remain until manually deleted.

**Q: Can I send to external email addresses?**
A: Only if external email integration is enabled. Contact administrator to set up.

**Q: Why can't I see someone in the recipient list?**
A: They may not have a K-Systems account or you may not have permission to message them. Contact administrator.

**Q: How do I report spam?**
A: Forward spam messages to your administrator and then delete them. They can configure filters.

**Q: Can I automate email sorting with rules?**
A: Depends on system configuration. Check Settings for "Rules" or "Filters" option, or ask administrator.
