# Desktop Apps & Games

K-Systems includes built-in desktop applications and games for productivity and entertainment.

## Overview

The desktop environment provides access to the following applications:

**Games:**
- **QuackleJump** - Flappy Bird-style arcade game
- **Minesweeper** - Classic mine-finding puzzle game
- **Solitaire** - Traditional Klondike solitaire card game
- **Sudoku** - Number puzzle game with difficulty levels

**Productivity Apps:**
- **Calculator** - Desktop calculator for quick calculations
- **WaterDuck** - Internal web browser for viewing company websites

## Games

### QuackleJump

A Flappy Bird-inspired game accessible from the desktop Start Menu.

**Features:**
- Arcade-style jumping game
- Launch from Start Menu → Tools & Utilities → QuackleJump
- Opens in desktop window

### Minesweeper

Classic mine-finding puzzle game with K-Systems branding.

**Features:**
- 10×10 grid puzzle game
- Flag mines and reveal safe cells
- Launch from Start Menu → Tools & Utilities → Minesweeper
- Opens in desktop window

### Solitaire

Traditional Klondike solitaire card game.

**Features:**
- Classic card game
- Drag-and-drop gameplay
- Launch from Start Menu → Tools & Utilities → Solitaire
- Opens in desktop window

### Sudoku

Number puzzle game with multiple difficulty levels.

**Features:**
- 9×9 grid number puzzle
- Multiple difficulty levels
- Launch from Start Menu → Tools & Utilities → Sudoku
- Opens in desktop window

## Productivity Apps

### Calculator

Desktop calculator for quick calculations.

**Features:**
- Basic arithmetic operations (+, −, ×, ÷)
- Percentage calculations
- Decimal support
- Clear and backspace functions
- Display shows current input and result

**How to Use:**
1. Click Start Menu → Tools & Utilities → Calculator
2. Opens in desktop window
3. Click numbers and operations to calculate
4. Press = to get result

**Calculator Layout:**
- Display area shows current expression and result
- Keypad with numbers 0-9
- Operations: +, −, ×, ÷, %, =
- C (Clear) and ⌫ (Backspace) buttons

### WaterDuck Browser

Internal web browser for viewing K-Systems company websites.

**Features:**
- Browse internal company websites
- View employee-created web pages
- Access from taskbar (pinned by default)
- Opens in desktop window

**How to Use:**
1. Click WaterDuck icon in taskbar (bottom bar)
2. Or: Start Menu → Tools & Utilities → WaterDuck
3. Browser opens in desktop window
4. Navigate to internal websites

## Opening Apps and Games

**From Start Menu:**
1. Click Windows icon in taskbar (bottom-left)
2. Navigate to "Tools & Utilities" section
3. Click app name to launch
4. App opens in new window

**From Taskbar (WaterDuck only):**
1. Look for WaterDuck icon in taskbar
2. Click icon to launch browser
3. Browser opens in new window

## Window Management

All apps and games open in desktop windows with standard controls:

**Window Controls:**
- **Title Bar**: Drag to move window
- **Minimize (−)**: Hide window to taskbar
- **Maximize (□)**: Expand to full screen
- **Close (×)**: Close the application

**Resizing:**
- Drag window edges or corners to resize
- Each app has minimum and maximum sizes

**Moving:**
- Click and drag title bar to reposition
- Position automatically saved

## Limitations

The following features mentioned in documentation **do not exist** in the current codebase:

❌ **Not Available:**
- Detailed game mechanics (score systems, power-ups, difficulty levels) are not documented in code
- Game scoreboards and high score tracking not verified
- Advanced calculator features beyond basic operations
- WaterDuck browser advanced features (tabs, bookmarks, history)
- Desktop icon shortcuts for individual apps (apps only accessible via Start Menu or taskbar)
- App settings and preferences
- Keyboard shortcuts for games
- Save game functionality

## Tips

**Productivity:**
- Use Calculator for quick math without opening spreadsheets
- Access WaterDuck from taskbar for fast browser access
- Games are in Tools & Utilities section of Start Menu

**Window Management:**
- Minimize apps when not needed instead of closing
- Use taskbar to switch between open windows
- Multiple apps can run simultaneously
