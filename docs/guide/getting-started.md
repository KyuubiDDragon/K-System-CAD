Welcome to K-Systems! This guide will help you get started using the system as an end user.

::: info For System Administrators
If you need to install or set up K-Systems, please see the **[Installation Guide](/guide/installation)** instead.
:::

## Accessing K-Systems

### First Time Login

![Login Screen](../public/images/login-screen.png)
*K-Systems login page*

1. **Open your web browser** and navigate to your organization's K-Systems URL
   - Example: `https://ksystems.yourcompany.com`

2. **Select your Organization**
   - Choose your organization from the dropdown menu
   - This is also called "Authority" in the system

3. **Enter your credentials**
   - **Username**: Provided by your administrator
   - **Password**: Your assigned password

4. **Click "Login"**

::: warning First Login
If this is your first time logging in, you'll likely need to change your password. Follow the prompts or go to your profile settings after logging in.
:::

## Understanding the Interface

K-Systems offers two interface modes to suit your preferences:

![Sidebar Mode](../public/images/sidebar-mode.png)
*Traditional sidebar navigation*

- **Left Sidebar** - Main navigation menu

![Desktop Mode](../public/images/desktop-mode-main.png)
*Windows-style desktop interface*

### 1. Update Your Profile

![Profile Settings](../public/images/profile-settings.png)

After logging in, take a moment to set up your profile:

1. Click your **name** or **avatar** in the top right corner

3. Update your information:

## Navigation Tips

### Using the Search Function

![Search Bar](../public/images/search-bar.png)

The search bar is your quickest way to find anything:

1. Click the **search icon** (🔍) or press `Ctrl+K` (Windows) / `Cmd+K` (Mac)
2. Start typing:
   - Module names (e.g., "employees", "reports")
   - Employee names
   - Document titles
   - Any content you're looking for
3. Select from the results to navigate directly

### Using the Sidebar Menu

The sidebar organizes features by category:
- **Records & Personnel** - Employee data, vacations, files
- **Documents** - Document management and sharing
- **Organization** - Company structure and applications
- **Operations** - Dispatch, vehicles, crews
- **Reports** - Reporting system
- **Communication** - Messages, calendar, boards
- **Collaboration** - Whiteboard, tasks
- **Maps** - Location tracking
- **Reference** - Help materials and templates

::: tip Collapsible Sidebar
Click the **hamburger menu** (☰) to collapse the sidebar and gain more screen space.

## Understanding Permissions

K-Systems uses a role-based permission system. Your access is determined by:

1. **Your Role** - Assigned by your administrator (e.g., Admin, Member, Manager)
2. **Module Access** - Which features you can use
3. **Permission Level** - What you can do (Read, Write, Delete)

### Common Permission Scenarios

**If you can't see a module:**
- You may not have been granted access to that feature
- Contact your administrator to request access

**If you can view but not edit:**
- You have "Read" permission only
- Request "Write" permission from your administrator if needed

**If an action is disabled:**
- You may lack the specific permission for that action
- Certain actions may be role-restricted

## Common Tasks

### Creating a New Report

1. Navigate to **Reports** in the sidebar
2. Click **"+ New Report"** button
3. Select a **report category**
4. Fill in required fields
5. Add any **attachments** or additional information
6. Click **"Save"** or **"Submit"**

**Learn more:** [Report Creation Workflow](/guide/workflows/report-creation)

### Uploading a Document

1. Go to **Documents**
2. Select the appropriate **document area**
3. Click **"Upload"** or **"+ New Document"**
4. Choose your file or create a new document
5. Set **permissions** (who can view/edit)
6. Click **"Save"**

**Learn more:** [Document Management Workflow](/guide/workflows/document-management)

### Checking Your Schedule

1. Open the **Calendar** module
2. View by **Day**, **Week**, or **Month**
3. Click on any event to see details
4. Your assignments are highlighted
5. Create new events with **"+ New Event"**

**Learn more:** [Calendar Guide](/guide/calendar)

### Sending a Message

1. Navigate to **Messages** or **Mail**
2. Click **"Compose"** or **"+ New Message"**
3. Select recipient(s)
4. Write your message
5. Optionally **attach files**
6. Click **"Send"**

**Learn more:** [Messages Guide](/guide/messages)
