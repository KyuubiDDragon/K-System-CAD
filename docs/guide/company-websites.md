# Company Websites

K-Systems includes a built-in website builder that allows you to create and manage public-facing websites for your organization.

![Website Management](../public/images/company-websites/website-overview.png)

---

## Overview

The Company Websites feature provides:
- **Website builder** with visual editor
- **Multiple websites** per organization (one per company/department)
- **Template system** for consistent branding
- **Content management** for pages, news, and galleries
- **Public access** for external visitors
- **Mobile-responsive** design
- **SEO optimization** tools

::: info Availability
Company Websites feature must be enabled by your administrator. Check if you have the `READ_COMPANY_WEBSITES` permission.
:::

---

## Accessing Website Management

### Opening the Module

**Via Sidebar:**
1. Navigate to **Organization** or **Company** section
2. Click **"Company Websites"** or **"Websites"**

**Via Search:**
1. Press `Ctrl+K` / `Cmd+K`
2. Type "websites"
3. Select from results

## Creating a Website

### Step 1: Create New Website

![Create Website](../public/images/company-websites/website-create.png)

1. **Click "+ New Website"** or **"Create Website"**

2. **Select company:**
   - Choose which company/department this website represents
   - One website per company

3. **Choose template:**
   - **Modern** - Clean, contemporary design
   - **Classic** - Traditional layout
   - **Minimal** - Simple, focused design
   - **Custom** - Start from scratch

4. **Enter basic information:**
   - **Website title** - Organization name
   - **Tagline/Slogan** - Brief description
   - **Domain/URL** - Website address (e.g., company-name.ksystems.com)

5. **Click "Create"**

### Step 2: Configure Website Settings

![Website Settings](../public/images/company-websites/website-settings.png)

**General Settings:**
- **Site title** - Appears in browser tab and search results
- **Description** - For search engines (SEO)
- **Contact email** - For contact forms
- **Phone number** - Displayed on website
- **Address** - Physical location

**Branding:**
- **Logo upload** - Your organization's logo
- **Favicon** - Small icon in browser tab
- **Colors** - Primary and secondary brand colors
- **Fonts** - Typography choices

**Social Media:**
- Facebook page URL
- Twitter handle
- Instagram profile
- LinkedIn company page
- YouTube channel

**Advanced:**
- **Custom domain** - Use your own domain (requires DNS setup)
- **Analytics** - Google Analytics tracking code
- **SEO settings** - Meta tags, keywords
- **GDPR compliance** - Cookie consent banner

## Content Management

### Pages

![Page Editor](../public/images/company-websites/page-editor.png)

**Default Pages:**
- **Home** - Landing page
- **About** - Organization information
- **Services** - What you offer
- **Contact** - Contact form and information
- **News** - Latest updates and articles

**Creating a New Page:**

1. **Go to Pages section**
2. **Click "+ New Page"**
3. **Enter page details:**
   - **Title** - Page name
   - **Slug** - URL path (auto-generated from title)
   - **Template** - Page layout type
4. **Add content** using page builder
5. **Publish** or **Save as Draft**

### Using the Page Builder

![Page Builder Interface](../public/images/company-websites/page-builder.png)

**Visual Editor:**
- Drag and drop sections
- Real-time preview
- Mobile/tablet view toggle

**Content Blocks Available:**

**Text Blocks:**
- **Heading** - Large titles (H1, H2, H3)
- **Paragraph** - Body text
- **Quote** - Highlighted quotations
- **List** - Bullet or numbered lists

**Media Blocks:**
- **Image** - Single or multiple images
- **Gallery** - Photo gallery with lightbox
- **Video** - YouTube/Vimeo embed
- **Document** - PDF downloads

**Layout Blocks:**
- **Columns** - Multi-column layouts (2, 3, 4 columns)
- **Accordion** - Collapsible sections
- **Tabs** - Tabbed content
- **Spacer** - Add vertical space

**Interactive Blocks:**
- **Contact Form** - Email contact form
- **Button** - Call-to-action buttons
- **Map** - Embedded Google Maps
- **Social Links** - Social media icons

**Specialty Blocks:**
- **Team Members** - Staff profiles with photos
- **News/Blog Posts** - Recent articles
- **Events Calendar** - Upcoming events
- **Testimonials** - Customer/community feedback

**Adding a Block:**
1. **Click "+ Add Block"** or drag from sidebar
2. **Select block type**
3. **Configure block settings:**
   - Content
   - Styling (colors, fonts, spacing)
   - Visibility (desktop/mobile)
4. **Preview** changes
5. **Save**

**Editing Blocks:**
- Click block to edit inline
- Click gear icon for advanced settings
- Drag handles to reorder
- Click X to delete

## News & Blog Management

### Creating News Articles

![News Editor](../public/images/company-websites/news-editor.png)

1. **Navigate to News/Blog section**

2. **Click "+ New Article"**

3. **Fill in article details:**
   - **Title** - Article headline
   - **Featured image** - Main image (shows in listings)
   - **Content** - Article body (use rich text editor)
   - **Excerpt** - Brief summary (for previews)
   - **Category** - Organize articles (Announcements, Events, Press Releases)
   - **Tags** - Keywords for filtering

4. **Set publication:**
   - **Publish immediately** - Goes live now
   - **Schedule** - Set future publish date/time
   - **Save as draft** - Work on later

5. **SEO settings:**
   - Meta description
   - Keywords
   - Social sharing image

**Article Formatting:**
- Use **headings** to structure content
- Add **images** throughout article
- Include **links** to related content
- Embed **videos** if relevant
- Break up text with **quotes** or **callouts**

### Managing News Articles

**Published Articles:**
- Edit - Make changes
- Unpublish - Remove from public view
- Duplicate - Create copy as template
- Delete - Permanently remove

**Organizing:**
- **Categories** - Group related articles
- **Tags** - Add searchable keywords
- **Featured** - Highlight important articles on homepage

## SEO & Analytics

### Search Engine Optimization

![SEO Settings](../public/images/company-websites/seo-settings.png)

**Page-Level SEO:**
- **Meta title** - Title shown in search results
- **Meta description** - Description in search results (155 characters)
- **Keywords** - Target search terms
- **Social sharing image** - Image for Facebook/Twitter shares

**Site-Wide SEO:**
- **Sitemap** - Auto-generated XML sitemap for search engines
- **Robots.txt** - Control search engine crawling
- **Schema markup** - Structured data for rich search results

**Best Practices:**
- Use descriptive page titles
- Write unique meta descriptions
- Include keywords naturally in content
- Use heading hierarchy (H1 > H2 > H3)
- Add alt text to all images
- Create descriptive URLs
- Link internally between pages

### Analytics Integration

**Google Analytics:**
1. Go to **Settings > Analytics**
2. Enter **Google Analytics Tracking ID** (e.g., UA-XXXXXXXXX-X or G-XXXXXXXXXX)
3. **Save**
4. Data appears in Google Analytics after 24 hours

**Built-in Statistics:**
- Page views
- Most visited pages
- Visitor geography (if available)
- Referral sources
- Device types (desktop/mobile/tablet)

## Publishing & Deployment

### Publishing Your Website

![Publish Website](../public/images/company-websites/publish-website.png)

**Before Publishing:**
- ✅ All pages reviewed and spell-checked
- ✅ Images optimized and have alt text
- ✅ Navigation menus configured
- ✅ Contact information correct
- ✅ Forms tested
- ✅ Mobile view checked
- ✅ Preview on different browsers

**Publishing Steps:**

1. **Click "Preview"** to review website
   - Check all pages
   - Test all links
   - Test contact forms
   - Review on mobile view

2. **Click "Publish"** when ready
   - Website goes live immediately
   - Accessible at configured URL

3. **Verify live website:**
   - Visit public URL
   - Test from external device
   - Confirm everything works

**Status Options:**
- **Draft** - Work in progress, not public
- **Published** - Live and accessible
- **Offline** - Temporarily hidden from public

## Troubleshooting

### Website Not Loading

**Check:**
- Website is published (not in draft mode)
- URL is correct
- DNS settings configured (for custom domains)
- Server is running

**Solutions:**
- Re-publish website
- Clear browser cache
- Contact administrator

### Images Not Displaying

**Possible causes:**
- Image file too large (use <2MB)
- Wrong file format (use JPG/PNG)
- Broken link
- Permissions issue

**Solutions:**
- Re-upload images
- Optimize image size
- Check image URLs

### Forms Not Submitting

**Check:**
- Contact email configured
- All required fields filled
- Internet connection
- Browser allows form submissions

**Solutions:**
- Test form yourself
- Check email settings
- Review form configuration
- Check spam folder for submissions

## Tips & Best Practices

### Content Strategy

**Homepage:**
- Clear value proposition
- Call-to-action buttons
- Recent news/updates
- Quick access to key pages

**About Page:**
- Organization history
- Mission and values
- Team members with photos
- Achievements and milestones

**Services:**
- Clear description of what you offer
- Benefits to community
- How to access services
- Contact information

**News:**
- Regular updates (at least monthly)
- Include photos
- Share on social media
- Keep articles concise (300-500 words)

### Design Tips

- Keep design simple and clean
- Use high-quality images
- Ensure good contrast for readability
- Make buttons clear and clickable
- Use whitespace effectively
- Stick to 2-3 fonts maximum
- Be consistent with colors

### Mobile Optimization

- Test on actual mobile devices
- Ensure text is readable without zooming
- Make buttons large enough to tap
- Minimize large images
- Simplify navigation for mobile
